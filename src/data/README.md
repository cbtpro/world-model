# 数据加载与模拟数据

## 职责

- `DataLoader<T>`：超时、取消、有限重试及错误分类，不依赖 Vue、HTTP 或 Three.js。
- `DataSource`：返回未经信任的 `unknown` 数据。`MockSource` 与 `HttpJsonSource` 是独立实现。
- `decodeSoftwareUsage`：校验并重新构建数据，拒绝非法坐标、重复 id、无效日期、非有限数值和异常规模。最多 5000 个地区，空数据合法。
- `softwareUsage` store：加载状态、可见性、选择及总量；新请求取消旧请求，并用请求序号阻止旧结果覆盖新状态。
- `SoftwareUsageLayer`：只消费已校验数据，使用球面高斯热力覆盖层绘制，经纬度方向与地球定位一致。支持选择、背面遮挡和资源释放。
- `SoftwareUsagePanel`：展示状态、图例与地区详情，保留加载失败前的数据并提供重试。

## 替换数据源

```ts
const loader = new DataLoader(
  new HttpJsonSource('/api/software-usage'),
  decodeSoftwareUsage,
)
const dataset = await loader.load({ signal, timeoutMs: 8000, retries: 1 })
```

新增数据源只需实现 `DataSource`，新增数据类型则注入独立校验器，无需修改加载器。接口鉴权可在自定义数据源中处理。非幂等请求应关闭自动重试。

取消、校验失败和 HTTP 4xx（429 除外）不自动重试；超时、网络错误、429 和 5xx 可有限重试。即使数据源忽略 AbortSignal，加载器也能及时结束等待。所有定时器和监听器在完成后清理。

## Mock 内容

`softwareUsage/mock.json` 是人工生成的演示数据，软件名 Atlas Workspace，日期 2026-10-04。覆盖 26 个城市，包含国家、经纬度、当日活跃用户和会话数。数值不代表真实使用情况。`isMock` 明确标注演示属性，UI 会显示“模拟数据 · 非真实统计”。

热力强度使用用户量的平方根比例，通过高斯核平滑扩散，邻近城市的热区自然融合。覆盖层贴合球面，透明渐变保留底图；颜色从青色经过橙色到红色。所有统计均针对此 mock 数据内的城市，不代表某国家或全球人口。

## 验证

`pnpm test` 覆盖数据校验、超时、取消、重试、背面选择及渲染资源释放；`pnpm build` 检查 Vue/TypeScript 和生产构建。

## 灾备拓扑与航班轨迹

`simulation/mock.json` 包含两组独立数据，由 `decodeSimulation` 校验后通过同一加载器读取：

- 灾备：上海、新加坡、法兰克福、伦敦、弗吉尼亚、俄勒冈共 6 个节点；3 条异地灾备链路及 2 条跨洲复制链路。主站为橙色，灾备站为蓝色，光点从源节点流向目标节点。延迟为模拟值。
- 航班：上海—旧金山、伦敦—纽约、新加坡—悉尼共 3 条航线。飞机沿大圆弧循环演示，轨迹在球面上方，速度不代表真实飞行时间。

`GeoRoutesLayer` 接收节点、连线及样式配置，拓扑和航班共用球面插值与资源管理；增加路线只需修改数据。跨日期变更线及反向端点的路径保持连续。节点 id、连线 id 必须唯一，连线必须引用存在且不同的节点，坐标和动画时长必须在有效范围内。

“模拟数据”面板统一归类软件热力图、灾备拓扑和航班轨迹。各图层独立开关；所有模拟数据图层默认关闭，地球视图中开启后显示。后台停止渲染，隐藏图层暂停演示动画；恢复前台不会累加后台动画时间。
